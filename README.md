Vice Cover Studio is an offline web app that turns your own photos and a caption into multi-panel GTA-style cover art: five panel layouts, per-panel crop and zoom, four Vice City colour grades, bold sunset lettering with a heat-star meter, and one-click PNG export in 1080×1080, 1080×1350 and 1920×1080. Photos never leave your machine — everything runs from static files in app/, and the artwork, lettering and demo scenes are original.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out node main.ts   # hands in app/ + screenshots/ + dossier.json
python3 -m http.server 8080 --directory app   # then open http://localhost:8080
```
